Each case draws the same quads, each with its own 80 bytes of uniform data (a mat4 and a vec4), and changes that data every frame in a different way: plain uniforms, one small uniform buffer rewritten before every draw, one big buffer uploaded once or in a write per draw, a ring of three big buffers, orphaning, and the same with only a tenth of the draws changing. "submit" is the CPU time of a frame's GL calls; "frame" the interval between frames; "gpu" how long a fence set after a frame's calls took to pass (checked every few ms: an upper bound on the frame's GPU and driver time). Every case runs twice, in reverse order the second time (heat and clocks drift over a run). Keep the screen on and don't touch it while it runs.
